## ③ 上位候補の詳細分析

### ◎⑧ ロブチェン — 能力と戦術の再現性を最重視

皐月賞は1分56秒5、ダービーは2分22秒7で勝利し、いずれも公式レーティング119。皐月賞の先行・逃げる競馬と、ダービーの中団から上がり33秒2で差す競馬を両立している。神戸新聞杯も5-7-8-4の通過順から勝利した。ただし前哨戦は接戦であり、他馬を圧倒したとまでは評価しない。[ロブチェン成績] [ダービー2026] [神戸新聞杯2026]

ワールドプレミア×母父Giant's Causeway。父系は延長を考える材料になるが、主たる根拠は競馬中に脚をため、位置取りを変えられる点にある。京都の重馬場の新馬戦勝ちもプラス材料だが、8頭立て2000mの実績であり、18頭の道悪3000mを保証しない。

松山との継続コンビ、4枠8番は序盤の位置を選びやすい。最終追いはCW4F52秒5、終い11秒1で、前週の負荷を経て整える調整。共同会見では落ち着きと状態面が評価されている。これらを大幅な能力上昇と置かず、崩れる兆候が乏しい程度の小さな加点にとどめた。[松山会見] [杉山会見] [栗東追切]

最も現実的な敗因は、初めての3000mで、外の早仕掛けを追いかけて長く脚を使い、最後の200mで②・⑩などに差される形。位置を下げすぎて進路確保が遅れる負け方もある。中心勝率36.9％、基礎評価を±2点した範囲は25.6～49.9％。この幅は信頼区間ではない。

### ○⑩ ダノンヒストリー — 長めの距離で実際に示した持続力

函館2600mの1勝クラスを2分37秒6、2着に2秒3差。札幌2600mの阿寒湖特別も2分39秒0、1秒3差で勝った。ともに55kgで、後方一気ではなく、3～4番手から前を捉えている。自身の上がりは35秒7、35秒6。この2走は、長めの距離で早めに動いて末脚を保ち、後続を大きく離した点を評価する。[函館2600] [阿寒湖特別]

ただし、函館のレース前半1000m59秒0は先頭馬の区間で、ダノン自身の1000m時計ではない。大逃げを追走した馬の負荷を、レース先頭のラップと同一視しない。阿寒湖特別の2着馬との3kg差もあり、着差をそのままGⅠの能力差へ換算しなかった。

エピファネイア×母父Tizway。血統より2600m2走の内容を優先した。ルメールへの交代は長距離の判断力という点で期待できるが、初コンビである。W5F67秒6、終い11秒7の調整は順調と判断する一方、70日ぶり、57kg、初京都、3000m、18頭立て、道悪は別の課題。良馬場以外の実証がなく、雨を歓迎する馬とは断定できない。[ダノン調整]

勝率11.7％は、条件戦組として高い評価だが不確実性も大きい。公式プレレーティングの空欄を「能力ゼロ」とせず、独自基礎点114から評価した。逆に、空欄の馬に公式117などの値が付いているかのような説明もしない。単勝の保守的購入条件は16倍以上。

### ▲② コンジェスタス — 着順以上に評価できる内容と内枠

京都新聞杯を2分09秒9、上がり35秒3で勝利。レース前半1000m58秒7という持続的な流れの中で結果を出した。ダービー9着は勝ち馬から0秒4、神戸新聞杯6着も0秒3差。着順だけを見て大敗扱いするのは不適切である。[京都新聞杯2026] [ダービー2026] [神戸新聞杯2026]

コントレイル×母キラモサ、母父Alamosa。血統は参考にしつつ、ゆったりした流れでも折り合えるという取材内容と、京都の持続戦で勝った事実を重く見る。最終追いは坂路54秒3、終い12秒2。前走からの上積みを少し認めるが、調教記事の高評価をそのまま勝率へ移してはいない。[コンジェスタス取材] [栗東追切]

1枠2番は距離を節約できる一方、534kgの大型馬が内で進路を失うリスクもある。神戸新聞杯では5-5-6-4と運び、上がり34秒1で6着だった。瞬発力勝負への過大評価は禁物。スローの最後600mだけなら⑤が上、持続戦なら②を上に置く。

## ④ レース展開予想

### コースが要求するもの

京都芝3000mは、向正面の上り坂からスタートし、最初の3コーナーまで約200m。外回りをおよそ1周半し、上り下りを2度通過する。外回りの高低差は4.3m、Aコースの直線は403.7m。最初の位置取り、下りで力まないこと、1周目のスタンド前での折り合い、2周目の進出位置が重要になる。[京都コース] [菊花賞コース解説]

直線だけで挽回する設計は危うい一方、早く先頭に立てばよいとも限らない。序盤は距離損を抑え、中盤は呼吸を整え、終盤は坂の上り下りに合わせて加速する能力の組み合わせを求める。

2023年の改修後も基本的なコース形状は大きく変わっていないが、外回り最終コーナーの形状、路盤・排水などには変更がある。2021・2022年の阪神開催を京都の枠順傾向へ混ぜず、改修前の京都とも完全に同一条件とはみなさない。[京都改修]

残り1600～1200m付近から⑮が動く可能性がある。ここで⑧・⑩がすぐに追いかけるか、少し待つかが核心になる。残り1000mでは②が進路を探し、⑨も後方のまま直線を待たずに位置を上げたい。最終4コーナーで⑧・⑩・②・⑤が射程内に入り、直線での持続力と余力を比較する形を本線とする。

## ⑤ オッズ・期待値評価

### 独立確率モデル

実売オッズは取得できておらず、現在の人気・予想オッズ・評論家の印はモデルの特徴量にしていない。能力・適性評価と市場価格の判断を分離した。

各馬のシナリオ別評価点を、基礎能力＋距離と折り合い＋状態＋枠＋ペース適合＋湿った馬場への適合で構成した。騎手、輸送、血統はこれらの解釈を助ける材料とし、同じ根拠を別項目で重ねて大きく加点しない。プレレーティングは対象レース・着順に掲載条件があるため、空欄を能力ゼロとは扱わず、年間の掲載値を能力の上限にも使わない。[JRAプレレーティング]

評価点をR、シナリオをsとして、強さを次式で置いた。

$$w_{i,s}=\exp\{(R_{i,s}-110)/3.75\}$$

110は計算上の基準で順位や確率に影響しない。3.75は評価点差から確率差への変換尺度で、過去データで学習した値ではない。1点差は相対的な強さ約1.31倍に相当するため、小さな点数差でも影響がある。

着順にはPlackett–Luce型の逐次選択モデルを使用した。同一シナリオで1着i、2着j、3着kとなる確率は、

$$P_s(i,j,k)=\frac{w_i}{W}\frac{w_j}{W-w_i}\frac{w_k}{W-w_i-w_j},\qquad W=\sum_h w_h$$

これを6つのシナリオ確率で加重平均する。馬連は上位2頭の順序を合算、ワイドは対象2頭を含む上位3頭の全順序を合算、3連複は該当3頭の6順序を合算した。各馬の勝率を単純に掛け合わせていない。共通の展開・馬場と、着順枠の奪い合いをモデル内で扱う。

実際に各シナリオ18P3＝4,896通り、計29,376通りを列挙した。勝率・連対率・3着以内率の合計、各券種の全組み合わせ確率、各馬の勝率≦連対率≦3着以内率を検査した。最頻の1～5着は18P5＝1,028,160通りを6シナリオで評価し、全順序の確率合計も確認した。**モンテカルロ・シミュレーションではなく、全順序の直接計算である。**

これは統計的に学習・校正・検証済みの競馬予測モデルではない。点数、温度尺度、展開確率の選び方は主観的である。さらに、シナリオ内では同じ強さの尺度を各着順に使い、馬ごとの不安定さや馬同士の進路妨害を完全には表さない。独立した競走中止確率、同着、極端な不良馬場も別建てにしていない。計算の整合性は確保したが、真の確率への近さは検証できていない。

### 能力順位と価格評価を分ける

能力・適性を合わせた順位は⑧→⑩→②→⑤→⑨。現在の市場価格がないため、馬券妙味の実順位はまだ算出できない。価格を確認する優先候補は②、⑩、⑤。⑮は大きな価格差がある場合だけの穴候補とする。

単勝オッズOに対し、損益分岐勝率は1/O、期待回収率はpO、期待利益率はpO−1。オッズには払戻の仕組みによる控除が既に反映されているので、pOからもう一度控除率を差し引かない。市場の相対的支持を分析するために逆数を正規化する作業と、購入の損益分岐1/Oは別である。[JRA馬券規則]

$$q=\min(hp,\ p_{\text{感度分析の最小}}),\quad h=0.8\;(\text{3連系は}0.7),\quad O_{\text{購入下限}}=1.10/q$$

割引率と10％の余裕は、推定誤差とオッズ変動に備えるための任意の判断基準であり、利益保証や統計的な下限ではない。感度分析の最小値に、さらに20％を掛けているわけではない。

### 予想を変える条件

- 雨が遅れ、時計の出る良馬場が維持される：⑨を引き上げ、⑤との順序を再検討する。
- 予報以上の雨で極端に消耗する不良馬場になる：現在の「湿」分岐の範囲を超える。全馬の確率を再評価し、購入を縮小または見送る。
- ⑬・⑱の取消などで先行構成が変わる：スロー確率を上げ、⑤・⑪の相対評価を見直す。
- ③・⑤の輸送後の消耗・強い興奮、⑥のハミ受け不安が明確になる：その馬の確率を下げる。体重の数字だけでは決めない。
- 土日午前の芝で、能力・ペースを考慮しても内外の通過位置による偏りが反復する：枠・進路補正を修正する。単発の大穴好走だけでは変更しない。
- ⑧の状態に客観的な異常や出走条件の変更がある：⑧軸の券をいったん撤回する。

**今回の予想で最も重要な3つの根拠**

1. ⑧の春の能力水準と、異なる位置取りから勝てる戦術の幅。

"""2026 Kikka Sho pre-race subjective scenario model.

No market odds are inputs. No fitting or backtest is claimed.
PL first-three probabilities are enumerated exactly, not Monte Carlo.
The five-place mode is enumerated from the same six-scenario mixture.
"""
import itertools
import json
import math
from pathlib import Path

ROOT = Path(__file__).resolve().parent
D = json.loads((ROOT / 'model_inputs.json').read_text())
N = len(D['names'])
NUMS = range(N)
PAIRS = list(itertools.combinations(NUMS, 2))
TRIPLES = list(itertools.combinations(NUMS, 3))
ORDERS = list(itertools.permutations(NUMS, 3))


def model(temp=None, dry=.4, pace=(.3, .5, .2), shifts=None):
    temp = D['temperature'] if temp is None else temp
    shifts = {} if shifts is None else shifts
    scenarios = []
    for wet, ground_weight in [(0, dry), (1, 1 - dry)]:
        for name, pace_weight in zip(['S', 'M', 'H'], pace):
            weight = ground_weight * pace_weight
            scores = [D['scores'][i] + D['pace' + name][i]
                      + wet * D['wet'][i] + shifts.get(i, 0) for i in NUMS]
            raw = [math.exp((x - 110) / temp) for x in scores]
            total = sum(raw)
            strengths = [x / total for x in raw]
            scenarios.append({'name': ('wet_' if wet else 'dry_') + name,
                              'weight': weight, 'strengths': strengths})

    ordered = {p: 0.0 for p in ORDERS}
    for s in scenarios:
        v = s['strengths']
        for i, j, k in ORDERS:
            p = s['weight'] * v[i] * v[j] / (1 - v[i]) * v[k] / (1 - v[i] - v[j])
            ordered[i, j, k] += p
    win = [0.0] * N
    top2 = [0.0] * N
    top3 = [0.0] * N
    quinella = {p: 0.0 for p in PAIRS}
    wide = {p: 0.0 for p in PAIRS}
    trio = {p: 0.0 for p in TRIPLES}
    for (i, j, k), p in ordered.items():
        win[i] += p
        top2[i] += p
        top2[j] += p
        for h in (i, j, k):
            top3[h] += p
        quinella[tuple(sorted((i, j)))] += p
        for pair in itertools.combinations(sorted((i, j, k)), 2):
            wide[pair] += p
        trio[tuple(sorted((i, j, k)))] += p

    checks = {'win': (sum(win), 1), 'top2': (sum(top2), 2),
              'top3': (sum(top3), 3), 'quinella': (sum(quinella.values()), 1),
              'wide': (sum(wide.values()), 3), 'trio': (sum(trio.values()), 1),
              'trifecta': (sum(ordered.values()), 1)}
    for label, (got, target) in checks.items():
        assert abs(got - target) < 1e-10, (label, got, target)
    assert all(0 <= win[i] <= top2[i] <= top3[i] <= 1 for i in NUMS)
    return {'scenarios': scenarios, 'win': win, 'top2': top2, 'top3': top3,
            'quinella': quinella, 'wide': wide, 'trio': trio,
            'trifecta': ordered, 'checks': checks}


def balanced_percent(values, total_percent):
    units = [x * 1000 for x in values]
    ints = [math.floor(x) for x in units]
    left = round(total_percent * 10) - sum(ints)
    order = sorted(NUMS, key=lambda i: units[i] - ints[i], reverse=True)
    for i in order[:left]:
        ints[i] += 1
    return [x / 10 for x in ints]


def serialize(m):
    out = dict(m)
    for kind in ['quinella', 'wide', 'trio', 'trifecta']:
        out[kind] = {'-'.join(str(i + 1) for i in k): v for k, v in m[kind].items()}
    return out

def wilson(x, n, z=1.959963984540054):
    p = x/n
    den = 1 + z*z/n
    center = (p + z*z/(2*n))/den
    half = z*math.sqrt(p*(1-p)/n + z*z/(4*n*n))/den
    return [max(0, center-half), min(1, center+half)]
