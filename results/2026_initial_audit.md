# 菊花賞予測モデル：初回検証レポート

**基準日：2026-10-25 / 予想原本：2026-10-23に保存**  
**対象：2026年菊花賞1レース・18頭 / 独立した未使用テスト：2026年の当該レースのみ**

## 再現性

保存済みモデルの6つの馬場・展開シナリオと評価点から、同じ係数 `T=3.75` で計算しました。

|---|---:|---:|
| ⑧ロブチェン | 36.9285% | 14着 |
| ⑩ダノンヒストリー | 11.7076% | 3着 |
| ②コンジェスタス | 10.3407% | 8着 |
| ⑤ジャスティンシカゴ | 9.5728% | 10着 |
| **⑨ゴーイントゥスカイ** | **6.1526%** | **1着** |

勝率合計100%、連対率合計200%、3着以内率合計300%。元モデルから計算結果を再現できました。

## 正式採点

| 指標（↓小さいほど良い） | 予想当時の元モデル | 18頭均等 |
|---|---:|---:|
| Log Loss | **2.788293** | 2.890372 |
| Multiclass Brier（18頭の二乗誤差合計） | **1.058388** | 0.944444 |
| Top2 multilabel Brier合計 | 2.157962 | 1.777778 |
| Top3 multilabel Brier合計 | 2.656853 | 2.500000 |

1レースの結果だけで、温度・距離補正・馬場配分を更新しない。Log Lossだけなら元モデルが優位、Brierでは均等モデルが優位であり、これだけでモデルの本質的な優劣を判定できません。

## 結果判明後の感度分析：正式バックテストには使用しない

| T | 元の乾湿40:60混合 勝者確率 | 乾のみ 勝者確率 | 混合のLog Loss |
|---:|---:|---:|---:|
| 3.00 | 5.17% | 7.54% | 2.962 |
| **3.75（予想原本）** | **6.15%** | **8.37%** | **2.788** |
| 4.50 | 6.67% | 8.65% | 2.708 |
| 6.00 | 7.03% | 8.57% | 2.655 |

大きいTでこの1レースのLog Lossが下がるのは事後的な現象です。**T=6または8へ変更する根拠にはなりません。** 実際の良馬場を結果判明後に使う計算も同様です。

## 入力の可用性と実行した検査

- 事前予測の原本はレース前（2026-10-23）に保存されています。原本SHA256で復元元を固定。
- 確定着順はJRA公式。レース日時は2026-10-25 15:40 JST、芝・良。
- 過去の2023～2025年の公式1～3着は別保存。ただし**事前モデル予測がないため検証・校正には使用していません**。
- レース前時点の全頭オッズがないため、**市場モデル・期待値・購入戦略のバックテストは未実施**。
- ウォークフォワードで利用可能な予測・結果ペアは1件。校正学習を行うための過去件数は0件、規定値30件を満たさないため**学習なし**。
- 時刻リーク・欠損・重複・確率の合計・元モデルの再現性について、17件のユニットテストが成功。

## 次の実装順序

1. 予想対象レースを増やし、各レースの**発走前時刻の予測**を保存する運用を開始。
2. 過去レースを遡る場合は、各特徴量が当時の発走前に利用可能だったことを検証した上で、レースごとの事前予測を構成。
3. 30レース以上が揃っても単純な係数合わせで結論を出さず、ウォークフォワードでモデル・市場の外部比較を実施。
4. 初距離・折り合い・展開シナリオは、十分なデータが揃ってから階層モデルやパフォーマンス分布として推定。
